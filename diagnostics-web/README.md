# DiagnosticsWeb

The Angular dashboard for DiagnosticService. It was generated with
[Angular CLI](https://github.com/angular/angular-cli) and now runs Angular 22
(`package.json`: `@angular/core` and `@angular/cli` `^22.2.1`).

## Development server

Run `npm start` (`ng serve`) for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload
if you change any of the source files. The dev server proxies through `proxy.conf.json`
(`angular.json`, `serve.options.proxyConfig`).

## Code scaffolding

Run `ng generate component component-name` to generate a new component. You can also use
`ng generate directive|pipe|service|class|guard|interface|enum|module`.

## Build

Run `npm run build` (`ng build --configuration production`) to build the project. The build artifacts are stored in
the `dist/` directory.

## Running unit tests

Run `npm test` to execute the unit tests with Jest (`jest --runInBand --coverage`). Karma was removed, and
`angular.json` defines no `ng test` target. `npm run test:mutation` runs StrykerJS over the Jest suite.
Run `npm run lint` for ESLint.

## Running end-to-end tests

There is no end-to-end test target in `angular.json` or `package.json`.
